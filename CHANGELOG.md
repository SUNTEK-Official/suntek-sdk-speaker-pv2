# Changelog

All notable changes to this repository are documented in this file.

## [1.0.0] - 2026-11-18

### Added
- Initial v1.0.0 embedded C firmware SDK release for SUNTEK PV2 smart cloud audio speakers.
- Included `sample-firmware/` application source tree, Makefile build scripts, and `sdk/` ARM `.a` libraries.
- Added Cloud Speaker API Spec V2.8.7 and PV2 SDK Operation Manual V1.0.0 (`docs/`).
